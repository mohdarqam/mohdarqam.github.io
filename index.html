Data Engineering

Retail Lakehouse with dbt and Airflow

A medallion lakehouse on Databricks and AWS S3, transformed with dbt and orchestrated with Apache Airflow on a simulated retail dataset.

dbt builds the Silver technical and business layers; the Gold layer is a One Big Table built with Jinja, then a star schema with SCD2 snapshots. Airflow runs it in order inside Docker, with tests as gates between layers.
